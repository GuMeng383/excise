## 一、先定三件事（这三件事决定了成败）

### 决定 1：跳过"Socket 联机版"，直接上 Web

原路线里的 P1（Socket + 自定义协议）对理解网络很有价值，但**它不产生可展示的东西**——没人会打开一个命令行客户端看你玩游戏。

- 收益对比：Socket 版 ≈ 面试可讲 1 个点；Web 版 ≈ 可演示、可写简历、可给别人玩。
- 折中方案：用 **2 个晚上**补"TCP 三次握手 / 粘包 / 线程池"的理论（面试够用），然后直接进 Spring Boot。

### 决定 2：1 月版**不含 AI**

AI 玩家放到 2027 年寒假（1 月中～2 月）做。理由：

- 6 周内做"联机 + 数据库 + 实时 + 部署"已经是满负荷；
- AI 版本放在 **2027 年 3～5 月投暑期实习时**才最值钱——那时你讲的是"我有记忆、会进化的 Agent"，而不是"我调了个 API"。

### 决定 3：技术栈锁死，不再选型

| 层 | 选型 | 理由 |
|---|---|---|
| JDK | **Temurin 21 (LTS)** | 你机器上是 25，太新，Spring Boot / Lombok 容易踩坑。装 21，`release=21` |
| 框架 | **Spring Boot 3.3.x** | 资料最多，Java 17+ 基线 |
| 持久层 | **MyBatis（手写 SQL）** | 学习价值最高，字节内部也大量用；不要一上来用 JPA 或 MyBatis-Plus |
| 数据库 | **MySQL 8**（本地 Docker） | 索引/事务/执行计划都要练 |
| 缓存 | **Redis 7**（第 6 周才引入） | 房间在线状态 + 限流 |
| 实时 | **原生 WebSocket**（不用 STOMP） | 少一层抽象，理解更透 |
| 认证 | **JWT**（jjwt） | 前后端分离最省事 |
| 前端 | **单个 HTML + 原生 JS** | 零框架，省下的时间全部投给后端 |
| 部署 | **Docker Compose + 一台学生机**（阿里云/腾讯云，约 10 元/月） | 有公网地址 = 有作品 |

> 模块结构（同仓库多模块）：
> ```
> excise/
>   excise-core/     ← 领域模型 + 游戏规则（你现在的代码搬过来，不依赖 Spring）
>   excise-server/   ← Spring Boot：Controller / Service / Mapper / WS
>   excise-console/  ← 原来的控制台版，保留，用来做回归验证
> ```

## 五、这 6 周你会踩到、也必须理解的坑

按出现顺序排列，每踩一个就记一条笔记：

| 坑 | 什么时候踩 | 背后原理 |
|---|---|---|
| 端口被占用 / 连接被拒 | W2 | 进程、监听端口、`netstat` |
| `ClassNotFoundException` / 版本冲突 | W2 | Maven 依赖仲裁、传递依赖 |
| `NullPointerException` 在 Service 层 | W3 | 分层后对象从哪里来、Spring 注入时机 |
| 事务不生效（`@Transactional` 自调用） | W3 | AOP 代理、Spring 事务原理 |
| 两个 WS 线程同时改房间状态出错 | W4 | 并发、锁、`ConcurrentHashMap` 的原子性边界 |
| 中文字符串乱码 | W2/W6 | 字符集：源码 → JDBC → 数据库 → 响应头 |
| Docker 里连不上 MySQL | W6 | 容器网络、`localhost` 的含义 |
| 时区差 8 小时 | W3 | `TIMESTAMP` vs `DATETIME`、`serverTimezone` |

**每一个坑都写进 `notes/踩坑记录.md`，面试时这就是你的"真实经验"。**

### 关于"大二寒假就找到实习"，说实话

- **大二寒假拿字节日常实习的概率不高**：日常实习一般要求每周到岗 3～4 天、连续 3 个月以上，这与大二下的课表直接冲突，而且你的项目深度还不够。
- **但值得投**：面试本身就是最高效的学习，被拒几次你会清楚差距在哪。目标定成"拿到 2～3 次面试机会"，而不是"拿到 offer"。
- **真正的第一个大机会是 2027 年 3～5 月的暑期实习**。那时你正好有：Web 版（1 月）+ AI Agent 版（2～4 月），两份作品、4 个月算法训练。这个组合在大二学生里属于前 10%。
